Methodology

ML Problem Formulation

RankPilot AI solves a multi-output supervised learning problem with two stages:

  1. Stage 1 — Multi-label Classification: Predict which of 7 actions apply to each page.
  2. Stage 2 — Scoring: For each applicable action, predict a score (0–100) representing urgency.

Model Training

Algorithm: XGBoost gradient boosted trees with binary logistic objective per action class.
Validation: Time-based train/val/test split with 5-fold TimeSeriesCrossValidation expanding window.
Label Generation: Weak supervision via SEO domain rules (Snorkel-style).

Explainability

SHAP (SHapley Additive exPlanations) provides per-prediction feature attribution. Tiered explanations: SHAP values for data scientists, surrogate decision trees for executives, and reason codes for practitioners.
